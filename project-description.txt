Project Name: Telegram Drive (Ad-Free & Hardened Edition)

Tech Stack: Tauri v2 (Rust backend) + React (TypeScript frontend) + Vite

Purpose: A cross-platform desktop app that turns a Telegram account into an unlimited cloud storage drive. Files are stored as messages in a Telegram chat, organized into "folders" (which are Telegram channels). The app includes media streaming, PDF viewing, archive extraction, and file sharing.

Key Architecture Points:
1. Auth Flow: User enters Telegram API credentials → phone number → verification code → 2FA password (if enabled) → session persisted locally
2. Storage Model: Each "folder" is actually a Telegram channel. Files are sent as document messages to that channel. The SQLite DB maps this virtual hierarchy.
3. Streaming: A local Actix-web server (bound to 127.0.0.1) serves media files via range requests. For video, it can create HLS playlists with multiple quality variants via FFmpeg transcoding.
4. Cross-platform: Desktop (Windows/macOS/Linux) via Tauri v2. Mobile (Android/iOS) with responsive React components and JNI bridges.
5. Security: All credentials stored locally. Streaming server uses dynamically generated per-session tokens. CSP blocks remote scripts/frames.
